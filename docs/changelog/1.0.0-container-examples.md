# 1.0.0 — Container examples

**Date:** 2026-10-15

**Changed**

- Added an `examples/` directory, grouped by topic so future non-container
  examples have a home. The first topic, `examples/container/`, holds six
  runnable scripts that demonstrate `Strukt\Container\Container` and the `app()`
  accessor through an order-service domain:
  - `01-bindings.php` — `instance()`, shared `set()`, transient `factory()`, `has()`.
  - `02-autowiring.php` — `get()` reflecting a constructor and resolving typed dependencies.
  - `03-interface-bindings.php` — binding an interface to a concrete class and swapping it.
  - `04-named-arguments.php` — `make()`/`app()` with named overrides, defaults, and the failure mode.
  - `05-app-and-psr11.php` — the shared container, PSR-11 behaviour, `alias()`, `setInstance()`.
  - `06-order-checkout.php` — a full checkout wired end to end with `new Container()`, then re-wired to a new gateway.
  - `07-the-app-helper.php` — the same checkout, including the notifier, wired entirely through the `app()` helper.
  - `08-fallback-default.php` — a `factory()` selector that falls back to a default (`instance()`) gateway when the live providers are unavailable, callable as `app('gateway')->pay(...)`.
- Added `examples/README.md` (topic index) and `examples/container/README.md`
  (run instructions, per-file index, and the container mental model).
- Added a `composer lint` script mirroring the other packages
  (`find src examples tests -name '*.php' -print0 | xargs -0 -n1 php -l`).

**Why**

- The container API only appeared in the README and tests; a guided, runnable
  set of examples makes the shared/transient/autowiring behaviour easier to
  learn and verifies the documented behaviour stays runnable.

**Documentation**

- `README.md`: added an "Examples" section pointing at `examples/container/` and
  the `composer lint` command under Testing.
- `examples/README.md`: new (topic index).
- `examples/container/README.md`: new.

**Tests**

- No unit tests added; the examples are demonstration scripts. They were run
  with `php examples/container/[0-9][0-9]-*.php` and pass, and are covered by
  `composer lint`. The `base` suite stays at 21 passing.

**Public API impact**

- None. Documentation, examples, and a local `lint` script only.
